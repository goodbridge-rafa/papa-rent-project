# Glossary (Dutch → English)

Dutch housing terms used in the code, the data and the app. Where a term is a Dutch legal concept with no direct English equivalent, keep the Dutch term even in English text. Amounts and thresholds are in `market-rules.md`, never here.

| Dutch term | Meaning |
|---|---|
| **Aanbodmodel** | Offer model based on registration time (seniority) |
| **Aftoppingsgrens** | Rent-capping threshold for huurtoeslag purposes (low: households of 1-2; high: 3+) |
| **AOW-leeftijd** | Statutory retirement age |
| **Antikraak** | Anti-squat: temporary caretaker occupancy |
| **AVG** | GDPR (Dutch name) |
| **Basisregistratie Personen (BRP)** | Municipal Personal Records Database |
| **Begeleid wonen** | Assisted/supported living |
| **Belastingdienst** | Tax and Customs Administration |
| **Bemiddelingskosten** | Brokerage/agency fee (may not be charged to the tenant) |
| **Bezichtiging** | Viewing |
| **Binding** (economische / maatschappelijke) | Economic / social ties to a municipality |
| **BSN (Burgerservicenummer)** | Citizen service number |
| **Burgerlijk Wetboek (BW)** | Civil Code |
| **Campuscontract** | Campus contract, conditional on enrolment |
| **CAO** | Collective labour agreement |
| **DAEB** | Services of General Economic Interest (the protected social branch of housing corporations) |
| **DirectKans / Direct te huur** | Instant-offer model: first eligible respondent wins |
| **Diplomatenclausule** | Diplomat clause (temporary letting while the owner is away) |
| **DigiD** | Government digital ID |
| **Doorstromer** | Someone who frees up a social home by moving (often given priority) |
| **Eerste reageerder** | First responder (to a listing) |
| **Eindafrekening servicekosten** | Annual service-charge settlement |
| **Energielabel** | Energy label |
| **Gebreken** | Defects |
| **Gelabelde woonruimte** | Labelled housing with restricted eligibility (youth, seniors, etc.) |
| **Grondwet** | Constitution |
| **Grote gezinnen** | Large families |
| **Hospitaverhuur** | Live-in subletting (the main tenant or owner lives in the home) |
| **Hospitavrijstelling** | Tax exemption for live-in subletting |
| **Hospiteren** | Roommate selection interview |
| **Huisvestingsverordening** | Municipal housing bylaw |
| **Huisvestingsvergunning (HVV)** | Housing permit |
| **Huurcommissie** | Rent Tribunal |
| **Huurdossier / Woondossier** | Digital rental application file |
| **Huurtoeslag** | Rent benefit |
| **Inkomensafhankelijke huurverhoging** | Income-dependent rent increase |
| **Inkomensgrenzen** | Income limits |
| **Inkomensverklaring** | Official income statement from the Belastingdienst |
| **Inschrijfduur / Meettijd** | Accumulated registration time |
| **Inschrijven** | To register |
| **Jongerencontract / Jongerenwoning** | Youth contract / youth housing |
| **Kale huur** | Net (bare) rent, excluding utilities and service charges |
| **KopieID** | Government app to mask the BSN on document copies |
| **Kwaliteitskortingsgrens** | Quality-discount threshold (huurtoeslag) |
| **Leegstandwet** | Vacant Property Act |
| **Liberalisatiegrens** | Liberalisation threshold: in current law, the upper limit of middenhuur (see `market-rules.md`) |
| **Lokaal maatwerk** | Local priority rules |
| **Loting** | Lottery |
| **Middenhuur / Middensegment** | Regulated mid-market rent |
| **MijnOverheid** | Citizen government portal |
| **Nieuwbouw** | New-build |
| **Nieuwbouwopslag** | New-build surcharge on middenhuur (exact rule not verified) |
| **Niet-DAEB** | The non-social (commercial) branch of housing corporations |
| **Nultredenwoning** | Step-free, accessible home |
| **Onderhuur (illegale)** | (Illegal) subletting |
| **Optiemodel** | Option model: preference option on a specific complex |
| **Overnamekosten** | Fixtures and fittings takeover cost |
| **Passend toewijzen** | Suitable allocation (rent matched to income) |
| **Prestatieafspraken** | Performance agreements between a housing corporation and the municipality |
| **Proeftijd** | Trial period |
| **Reageren** | To respond/apply to a listing |
| **Reactie met motivatie** | Response with a motivation letter |
| **Salarisstrook** | Payslip |
| **Scheefwonen** | Income-housing mismatch (higher income in a social home) |
| **Seniorenwoning** | Senior housing |
| **Servicekosten** | Service charges |
| **Situatiepunten** | Situational points (social circumstances) |
| **Sleutelberoepen** | Key/essential professions |
| **Sleutelgeld** | Illegal key money |
| **Sociale huur** | Social housing |
| **Spookinschrijving** | Fictitious (ghost) BRP registration |
| **Startpunten** | Starter points (when leaving a youth contract) |
| **Statushouder** | Asylum status holder |
| **Studentenhuisvesting** | Student housing |
| **Toegelaten instelling** | Registered social landlord (housing corporation) |
| **Tussenhuur** | Interim/temporary sublease |
| **Tweedekans-contract** | Second-chance contract |
| **Urgentieverklaring** | Urgency declaration/status |
| **Vast contract / voor onbepaalde tijd** | Indefinite-term contract |
| **Verhuurdersverklaring** | Statement from the previous landlord |
| **Verhuurvergunning** | Municipal landlord licence |
| **Vermogenstoets** | Asset/means test |
| **Verzamelinkomen** | Aggregate taxable income |
| **Vrije sector** | Free (unregulated) market |
| **Vrije toewijzingsruimte** | Discretionary allocation margin |
| **Wachtpunten** | Waiting points |
| **Werkgeversverklaring** | Employer's statement |
| **Wet betaalbare huur** | Affordable Rent Act |
| **Wet goed verhuurderschap** | Good Landlordship Act |
| **Wet vaste huurcontracten** | Fixed Tenancy Contracts Act (in force 1 July 2024; see `temporary-contracts.md`) |
| **Woningcorporatie** | Housing association/corporation |
| **Woningdelen** | Regulated shared housing |
| **Woningruil** | Home swap |
| **Woningwaarderingsstelsel (WWS)** | Housing Valuation (points) System |
| **Woningwet** | Housing Act |
| **Wooncoöperatie** | Housing cooperative |
| **Woonpunten** | Housing points (Amsterdam region) |
| **Woonruimteverdeelsysteem** | Regional housing-allocation system |
| **Woonwensprofiel** | Housing-preference profile |
| **WOZ-waarde** | Municipal assessed property value |
| **WOZ-cap** | Cap on the WOZ component of WWS points (exact rule not verified) |
| **WSW** | Social Housing Guarantee Fund |
| **Zelfstandige woonruimte** | Self-contained dwelling (own entrance, kitchen and toilet) |
| **Zoekpunten** | Search-activity points |
